AllianceLab v1.0.0 is the first stable release of an offline FRC scouting workspace by Abhijay Panwar.

Create an event, collect match and pit observations, compare teams, and prepare alliance choices with transparent priorities. Share observations through reviewed JSON imports, CSV exports, and multipart QR transfers. Every application screen is cached for offline use after the first successful load.

Start with the labeled demo event or create your own roster and metric setup. Scouting totals and pick scores are estimates; they are not official match scores or win probabilities.

The web ZIP contains a static production build. Serve its contents from HTTPS or localhost. See the README and deployment guide for setup, offline checks and backup recommendations.

Saved scouting data stays in your browser. Export a JSON backup after each session. Physical camera behavior and browser installation prompts vary by device; QR image and file-transfer fallbacks are included.
